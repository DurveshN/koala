# Upstream Source

Koala began from an independent source import of OpenCode.

- Repository: https://github.com/anomalyco/opencode
- Release: `v1.18.31`
- Upstream commit: `014614d35b397775e5d397a490fc72368c894ec2`
- Import date: 2026-09-17
- Koala baseline commit: `41880aa`
- Upstream license: MIT

The upstream Git metadata was removed after verifying the release commit. Koala
uses an independent `dev` branch and commit history. Selected upstream changes
must be reviewed and imported explicitly rather than merged implicitly.

The OpenCode MIT notice is retained in `THIRD_PARTY_NOTICES.md` and must remain
available with source and binary distributions containing substantial OpenCode
code.
