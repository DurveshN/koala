# Koala Model Discovery API

## Files

- `packages/opencode/src/koala/model-discovery.ts` defines the discovery schemas, typed errors, service, layer, and `LayerNode`.
- `packages/opencode/src/server/routes/instance/httpapi/groups/model-profile.ts` declares `POST /global/model-profile/discover` and its 400, 500, 502, and 504 responses.
- `packages/opencode/src/server/routes/instance/httpapi/handlers/model-profile.ts` maps discovery errors to the declared public errors without using profile storage or global disposal.
- `packages/opencode/src/server/routes/instance/httpapi/server.ts` adds the discovery node to the server graph.

## Contract

The service accepts a Koala provider ID, canonical Koala base URL, and optional transient API key represented by `Schema.Redacted`. A transient key bypasses stored auth lookup. Otherwise, an `Auth.Api` key is used, missing auth is anonymous, and OAuth or well-known auth is rejected as unsupported.

Discovery trims trailing slashes from the root path and requests exactly `<root>/models`. Roots already ending in `/models` are rejected. The bound `ModelEndpointClient` performs the request once, with no retry, and continues to own redirect denial and endpoint address policy. The whole discovery operation has a fixed five-second timeout.

Successful responses are limited to 1 MiB through Core's bounded HTTP response collector. The service accepts the OpenAI-compatible `{ "data": [{ "id": string }] }` envelope, strips extra fields, limits input to 10,000 entries, trims model IDs, rejects blank, control-character, and greater-than-512-character IDs, and deduplicates case-sensitively in first-seen order. The result contains only `{ models: [{ id }], duplicateCount }`.

## Security Choices

- Discovery uses the already-bound model endpoint transport, so DNS resolution, private/loopback restrictions, path scope, unsafe header rejection, proxy bypass, and redirect denial remain centralized.
- Authorization is omitted for anonymous requests and set to `Bearer <key>` only when a transient or stored API key exists.
- The transient key schema rejects empty values, redacts decode failures, and disallows JSON encoding of the runtime redacted value.
- Domain error messages are constant and do not include URLs, query strings, response bodies, credentials, redirect locations, resolver errors, or transport exception text.
- Response status is the only upstream detail retained, and only on the typed endpoint error.
- The handler does not call `ModelProfileStore`, auth mutation methods, configuration mutation methods, or global instance disposal.

## Risks

- The private-interface test returns without opening a server on hosts that expose no private interface; loopback, public-address, mixed-resolution, and metadata policy coverage remains in the endpoint-client suite.
- The HttpApi exercise intentionally uses an invalid `/models` root and verifies a deterministic 400 response rather than depending on an external model server.
